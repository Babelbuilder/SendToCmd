# SendToCmd 2.1.0 — Multiple command file tabs / 多文件标签页

## 中文

新增类似 Notepad++ 的多文件标签页，可同时打开不同设备或测试流程的命令清单。

- 新建文件增加独立标签；打开支持多选，重复打开同一文件会切换到已有标签。
- 每份文件独立保留文本、修改状态、撤销记录、光标、滚动位置和发送起止行。
- 标签支持拖动排序、关闭按钮、未保存 `*` 标记和完整路径提示。
- Ctrl+Tab / Ctrl+Shift+Tab 切换标签；Ctrl+W（macOS Cmd+W）关闭当前标签。
- 关闭或退出时检查未保存修改，支持保存、放弃和取消；关闭最后一页后保留新的空白页。
- 切换标签会停止自动发送并取消等待中的输入。已经送到终端的内容不能撤销。终端绑定和输入设置仍共用。

验证与下载：

- **Windows x64：用户已实机测试此次标签页版本并确认正常。** 单文件 EXE，不需要额外 Qt/MinGW DLL。保留用户测试过的原始字节；对应源码提交记录在 `WINDOWS-SOURCE-COMMIT.txt`。当前未进行受信任代码签名。
- **Ubuntu 24.04 x64：未做用户实机功能测试。** 使用 `sudo apt install ./SendToCmd-2.1-Ubuntu-24.04-x64-untested.deb` 安装并自动安装依赖。外部终端控制需要 X11；Wayland 不支持。
- **macOS Intel x64 / Apple Silicon arm64：未做用户实机功能测试。** DMG 包含 Qt 运行库；有临时签名，但没有 Developer ID 签名或公证。外部输入需要辅助功能权限。

## English

Adds Notepad++-style document tabs for command lists belonging to different devices or test workflows.

- New creates a separate tab. Open supports multiple files and focuses an existing tab when opening the same file again.
- Each document preserves its text, modified state, undo history, cursor, scroll position and send-range markers independently.
- Tabs support drag reordering, close buttons, unsaved `*` indicators and full-path tooltips.
- Ctrl+Tab / Ctrl+Shift+Tab switch tabs; Ctrl+W (Cmd+W on macOS) closes the active document.
- Closing documents or exiting checks unsaved changes and supports Save, Discard and Cancel. Closing the last tab creates a blank document.
- Switching tabs stops auto send and cancels pending input. Already delivered input cannot be undone. Terminal binding and input settings remain shared.

Verification and downloads:

- **Windows x64: the user tested this tabbed version on Windows and confirmed it works.** Standalone EXE without separate Qt/MinGW DLLs. Preserves the exact tested binary; its source commit is recorded in `WINDOWS-SOURCE-COMMIT.txt`. No trusted code signature.
- **Ubuntu 24.04 x64: not functionally tested on a user's machine.** Install with `sudo apt install ./SendToCmd-2.1-Ubuntu-24.04-x64-untested.deb`; apt installs dependencies. External terminal control requires X11 and is unavailable on Wayland.
- **macOS Intel x64 / Apple Silicon arm64: not functionally tested on a user's machine.** DMGs contain Qt libraries, with ad-hoc signing but no Developer ID signature or notarization. External input requires Accessibility permission.

Local compilation and all three automated test suites precede online platform builds. Compilation, automated tests and package checks do not establish real terminal interaction acceptance. Assets include SHA256 checksums. Previous 2.0 and archived 1.0 releases remain available.

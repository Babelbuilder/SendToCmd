# SendToCmd 2.0.0

## 中文

Windows 2.0 正式发布：用户已在 Windows 上测试基本功能正常。本次发布保留该已测试 EXE，不重新编译替换。

- Windows x64：单文件 EXE，不需要另外放置 Qt/MinGW DLL。当前未签名。
- Ubuntu 24.04 x64：DEB 包，**未做用户实机功能测试**。请使用 `sudo apt install ./SendToCmd-2.0-Ubuntu-24.04-x64-untested.deb` 安装，依赖由 apt 安装。外部窗口绑定/发送需要 X11 会话；Wayland 不支持此功能。
- macOS：分别提供 Apple Silicon (arm64) 和 Intel (x64) DMG，包含 Qt 运行库，**未做用户实机功能测试**。未进行 Developer ID 签名和公证。外部窗口发送需要授予辅助功能权限。

功能包括：命令文本编辑、文件操作、行号和当前行高亮、拖动绑定外部终端、发送当前行（F8）、发送后回车并指向下一行（含空行）、起止行标记和可设置间隔的自动发送、中英文界面、剪贴板或键盘输入及可配置粘贴快捷键。

Ubuntu/macOS 的自动化测试不代表外部终端输入已经验证。请报告平台、终端、输入方式和复现步骤。`SHA256SUMS.txt` 用于校验附件完整性。

## English

Windows 2.0 is released after the user verified its basic functionality on Windows. This release preserves the tested EXE rather than rebuilding it.

- Windows x64: standalone EXE, no separate Qt/MinGW DLLs required; currently unsigned.
- Ubuntu 24.04 x64: DEB package, **not functionally tested on a user's machine**. Install with `sudo apt install ./SendToCmd-2.0-Ubuntu-24.04-x64-untested.deb`; apt installs dependencies. External window binding/input requires an X11 session and is unavailable on Wayland.
- macOS: separate Apple Silicon (arm64) and Intel (x64) DMGs with Qt runtime libraries, **not functionally tested on a user's machine**. No Developer ID signature or notarization. Accessibility permission is required for external input.

Features: text/file editing, line numbers and current-line highlighting, drag-to-bind external terminals, send current line (F8), Enter and next-line advancement including blank lines, range markers and configurable auto-send interval, English/Chinese UI, clipboard/keyboard input and configurable paste shortcuts.

Automated Ubuntu/macOS tests do not verify real terminal interaction. Report platform, terminal, input mode and reproduction steps when filing issues. Use `SHA256SUMS.txt` to verify downloaded assets.
